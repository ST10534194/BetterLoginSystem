# QuickChat Application

## Overview

QuickChat is a Java console application developed using NetBeans and Maven.

The system allows users to:
- Register accounts
- Login securely
- Send messages
- Store messages in JSON format
- Generate unique message hashes
- Validate usernames, passwords, and cell numbers
- Run automated unit tests using JUnit

This project was developed as part of the Programming POE assignment.

# Project Features

## Part 1 – Registration & Login
- Username validation
- Password complexity checks
- South African cell number validation
- User registration

## Part 2 – QuickChat Messaging
- Welcome to QuickChat menu

- Message hash generation
- Auto-generated message IDs
- Message length validation
- JSON storage
- Loop-based menu system
- Total messages counter
- JUnit testing

## Part 3 – Advanced Reporting & Management
- Parallel array architecture for global message tracking
- Display all saved senders and recipients
- Find and display the longest message saved
- Search and view messages via unique Message ID
- Filter and view all messages linked to a specific recipient cell number
- Delete messages across all arrays using unique Hash Key
- Print complete system report
- Instant mock test data population feature
- Automated JUnit testing for all data handling algorithms
